Ammu Bestie Website

How to deploy:
1. Extract this ZIP file.
2. Upload the full folder contents to your hosting/public_html folder.
3. Make sure index.html, styles.css, script.js, and assets folder stay together.
4. Open your domain. The website is static and needs no backend setup.

Customize text:
- Open index.html
- Replace Ammu or any message with your own words
- Save and deploy again
